## 🚀 লোকাল সার্ভারে টেস্ট করার নিয়ম

আপনার কম্পিউটারে টার্মিনাল বা কমান্ড প্রম্পট খুলে এই ফোল্ডারে রান করুন:

```bash
cd "smart-watch"
php -S 127.0.0.1:8095
```

এরপর যেকোনো ব্রাউজারে প্রবেশ করুন:
- ল্যান্ডিং পেজ: `http://127.0.0.1:8095`
- অ্যাডমিন ড্যাশবোর্ড: `http://127.0.0.1:8095/admin.php`

## 🌐 cPanel / যেকোনো হোস্টিংয়ে আপলোডের নিয়ম

1. `smart-watch` ফোল্ডারের ভেতরের সব ফাইল জিপ (zip) করুন।
2. cPanel এর `public_html` অথবা সাব-ডোমেইনে ফাইলগুলো আপলোড করে আনজিপ (extract) করুন।
3. কোনো ডাটাবেজ কনফিগারেশনের প্রয়োজন নেই, সাথে সাথে সাইট সম্পূর্ণ লাইভ ও ফাংশনাল হয়ে যাবে!
